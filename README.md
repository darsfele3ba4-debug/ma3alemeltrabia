# مدارس معالم التربية — Maalem Al Tarbeiah Schools

ألعاب تفاعلية لمادة الرياضيات — الصف الرابع الابتدائى — الفصل الثانى: الجمع والطرح.

درس واحد: **مهارة حل المسألة + الجمع** (التقدير أم الإجابة الدقيقة، التقريب، الجمع مع إعادة التجميع، مسائل لفظية).

- `index.html` : الصفحة الرئيسية
- `game.html?l=1` : ألعاب الدرس
- `data/1.js` : أسئلة الدرس — 6 ألعاب: تسجيل الأهداف، شد الحبل، صح أم خطأ، التوصيل، الفقاعات، التنشين (6 × 15 سؤالًا، بدون وقت محدد)
- `assets/img/logo.png` : شعار المدرسة
- `assets/` : التصميم ومحرك الألعاب والمؤثرات الصوتية (تعمل بدون إنترنت عدا الخط)

الصوت: تصفيق وهتاف مع كل إجابة صحيحة، ونغمة حزينة مع الإجابة الخاطئة، مع عبارات تشجيع متغيرة فى كل مرة (زر كتم الصوت أعلى الصفحة).
